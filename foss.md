# Free and Open Source Software

    - [ALSXT Dash Ability](/Voidware-Prohibited/AlsxtDashAbility): GAS-based Dash Ability Modular Game Feature for ALSXT

## Target Vector

Rewrite the Rules of Engagement
A Complete, Modular and Dynamic UE5 Game Framework for AAA Online Games leveraging cutting-edge tech like GAS, EOS, World Partitioning, Level Instancing, PCG, Game Features, CommonUI, ALSXT, Aurora, Clima, Ricochet and more.

- [Arcana](/Voidware-Prohibited/Arcana): Make Magic. Serialized Smart Object Spawning Subsystem and Contextual Character Interaction System with GAS and World Parition Support.
- [Archon](/Voidware-Prohibited/Archon): God-Mode, Admin, Moderation with GAS, EOS and Abraxas support.
- [Arsenal](/Voidware-Prohibited/Arsenal): GAS-based, Tetris-style Inventory System.
- [Aurora](/Voidware-Prohibited/Aurora): Serialize, Initialize, Deserialize and Import Server Maps to and from JSON or PostgreSQL Database
- [Axos](/Voidware-Prohibited/Axos): Lead The Way. Replicated True North Game State Component
- [Choros](/Voidware-Prohibited/Choros): EOS-based Voice Chat and Text Chat with Net Compartmentalization, GAS and Moderation support.
- [Chronos](/Voidware-Prohibited/Chronos): Seize The Day. A Customizable, data-driven, in-game, multiplayer Calendar, Time and Event System.
- [Clima](/Voidware-Prohibited/Clima): A Parametric, Multiplayer Weather system with Micro-Climates for UE5 utilizing GAS and World Partition System
- [Echelon](/Voidware-Prohibited/Echelon): Server-Authoritative Unit Organization and Chain of Command API.
- [Exemplar](/Voidware-Prohibited/Exemplar): Cross-platform Performance Profiling for CI/CD
- [Helios](/Voidware-Prohibited/Helios): Recording and Instant Playback plugin (Sends to Archon)
- [Kairos](/Voidware-Prohibited/Kairos): Dynamic, Procedural Mission and Objective System
- [Travos](/Voidware-Prohibited/Travos): Replicated Dynamic Landscape and Mesh Painting System with World Partition support.
- [Ricochet](/Voidware-Prohibited/Ricochet): Realistic, GAS-based, Network-predicted, Ballistics for UE5
